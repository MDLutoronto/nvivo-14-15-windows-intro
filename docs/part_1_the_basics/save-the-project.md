Save the Project
----------------

1. While NVivo will ask you to save your project every 15 minutes, when you are done working on a project it is important to remember to save manually. **From the File Menu, select Save** to save the current project.

    <img src="{{ '/assets/images/NVivo15_intro_091.png' | relative_url }}" alt='Red box around the file menu.' title='' width='623' height='392' />

    <img src="{{ '/assets/images/NVivo15_intro_092.png' | relative_url }}" alt='In the file menu, red box around Save.' title='' width='524' height='381' />

2. You can also save a project by clicking on the floppy disk icon on the top right of the menu bar, or pressing **CTRL\+S** on your keyboard.

    <img src="{{ '/assets/images/NVivo15_intro_093.png' | relative_url }}" alt='Save button is highlighted' title='' width='1477' height='116' />

3. Finally, you can close a project to return to the NVivo main screen. Once your project is saved, **go back to the File Menu and select Close**.

    <img src="{{ '/assets/images/NVivo15_intro_094.png' | relative_url }}" alt='In the file menu, red box around Close.' title='' width='539' height='376' />
